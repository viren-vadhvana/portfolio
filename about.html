Academic Project Highlights

Software Development ▼

  • DVD Store Database:Architected a database schema for a DVD store and implemented using MySQL. Interfaced with a simple static website.

  • Cybersecurity Dashboard: Built an ESRC-backed tool visualising cyber threat vulnerabilities for a specific company and suggesting countermeasures providing optimal ROI given a set of constraints.
  • UI/UX Prototyping: Designed a funfair app prototype in Figma backed by ethnographic research and heuristic usability evaluations.
  • Software Specification: Authored a complete requirements and stakeholder specification for a real estate application.
Data Science and AI/ML ▼
  • Classifying Illicit Bitcoin Transactions: Trained temporal Graph Neural Networks (tGNNs) on the Elliptic dataset to detect illicit transactions, enriched with news sentiment and market volatility.
  • Conversational NLP Flight Bot: Built a flight-booking chatbot using NLP, focusing on user experience, AI explainability and contextual error handling.
  • Air Quality Prediction: Trained and evaluated classical machine learning models (linear regression, random forests, SVMs etc.) to predict air quality over time.
  • Mushroom Classification: Trained and evaluated classical machine learning models (logistic regression, decision trees, KNN etc.) to classify mushrooms as edible or poisonous.
  • Breast Cancer Classification: Applied deep learning techniques to the breast cancer dataset to classify malignant and benign tumours
  • Flower Classification:Trained and evaluated various models to classify flowers using the classic Iris dataset.
Security ▼
  • Pen-Testing a Vulnerable Ubuntu Server: Assessed a server's security using various attacking techinques (packet-sniffing, password cracking, SQL-injection, privilege escalation, etc.) and then secured against vulnerabilities (setting up encryption, access-control, iptables/firewalls, antivirus, updates etc.)
  • Accountability in Algorand: Solved the non-attribution flaw in Algorand using Timed VRFs and added a reputation metric to disincentivise malicious behaviour. I then proved by simulation that the "Proof of Effective Stake" consensus mechanism effectively disincentivised adversarial behaviour.
  • Decentralised Mixing Protocol: Designed a theoretical mixing protocol with mathematical proof that pseudonymity is maintained under coordinated adversarial attack models.
  • Implemented Ciphers: Implemented various ciphers and cryptographic primitives. E.g. DES, AES-GCM, ChaCha20, Trivium, and XTS.
Hardware and Low-level ▼

  • Ultrasonic Carriage Counter: Built a rule-based, real-time footfall tracking system for a train carriage using a Raspberry Pi, a GrovePi board, and ultrasonic/PIR sensors.
  • OS Scheduling Algorithm: Implemented a scheduling algorithm with a priority queue, using semaphores and mutexes to lock processes, plus paging and segmentation memory management.
Math and Theory ▼

  • Finite Automata and Turing Machines: Analyzed computational limits using finite state automata, Turing machines, and Master Theorem complexity analysis.
  • Essay on the Ethics of Cryptocurrency Mixers: Authored an analytical essay examining cryptocurrency mixers through diverse ethical and regulatory frameworks.
